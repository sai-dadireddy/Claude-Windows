================================================================================
                          HOW TO CUSTOMIZE FOR YOUR TENANT
================================================================================

STEP 1: Copy the scripts to your project folder

STEP 2: Edit the CUSTOM DATA VARIABLES section in each script:

   BEFORE (default values):
   {{TENANT_LOGIN_URL}} = https://impl-identity.wd12.myworkday.com/...
   {{USERNAME}} = stud_isu
   {{PASSWORD}} = Erpa@1234
   {{HIRE_FIRST_NAME}} = John

   AFTER (your tenant values):
   {{TENANT_LOGIN_URL}} = https://your-tenant.workday.com/...
   {{USERNAME}} = your_username
   {{PASSWORD}} = your_password
   {{HIRE_FIRST_NAME}} = YourTestEmployee

STEP 3: Load the script in Electron DSL Tool

STEP 4: Execute and verify each step completes successfully

================================================================================
                            HOW TO USE IN ELECTRON APP
================================================================================

1. Open the Electron Test Accelerator app
2. Load the script file (BEN-4-0010-01...txt)
3. The app reads the AUTOMATED STEPS section
4. Variables are substituted with values from CUSTOM DATA VARIABLES
5. Steps execute sequentially with built-in waits

IMPORTANT NOTES:
- Password entry may require manual input (security restriction)
- Click cancel button is used as safe exit when tenant lacks test data
- All field interactions use the select command for consistency

================================================================================

| Command Pattern                    | What It Does                          |

| select {Field} as {{VALUE}}        | Selects value in dropdown/field       |
