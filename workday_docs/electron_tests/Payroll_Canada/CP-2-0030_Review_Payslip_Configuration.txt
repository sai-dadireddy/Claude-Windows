DESCRIPTION:
Run a pay calculation for an employee and go to the employee's pay results. Review the payslip (Related Action > Payroll Result > View Payslip) to ensure that payslip is displaying as per requirements. Enter additional payroll input and re-calculate pay result as needed to make sure all Pay Component Groups linked on the Payslip Configuration can be confirmed to be working as expected. Note: Payslip is the online view and may differ from the check print layout. The check print layout can be viewed online as a PDF.

WORKDAY ROLE: Payroll Partner
EST. DURATION: 15 minutes
COUNTRY SCOPE: CA

PREREQUISITES:
- User logged in with Payroll Partner permissions
- Required data available in tenant
- Access to CA payroll data
- Pay calculation run completed for test employee
