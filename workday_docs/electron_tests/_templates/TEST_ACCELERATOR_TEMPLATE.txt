SECTION 7: COMMON PATTERNS
================================================================================

### Pattern: Dropdown Selection
Click {{DROPDOWN_FIELD}}

Wait for 1 seconds
Select {{OPTION_VALUE}}

### Pattern: Multi-Select Widget (Workday)
Click {{MULTISELECT_FIELD}}
Wait for 1 seconds
Enter {{SEARCH_VALUE}} in search
Wait for 1 seconds
Click {{OPTION}}
Click OK button

### Pattern: Date Field
Click {{DATE_FIELD}}
Enter {{DATE_VALUE}} in date field
Press Tab

### Pattern: Report Execution
Click Run button
Wait for 10 seconds
Verify page contains Report completed

### Pattern: Table Verification
Verify ALL records in {{COLUMN}} column have {{VALUE}} across all pages

SECTION 9: WAIT TIME GUIDELINES
================================================================================

| Action | Wait Time | Reason |
|--------|-----------|--------|
| After login | 5 seconds | Dashboard load |
| After search | 2 seconds | Search results |
| After page nav | 3-5 seconds | Page render |
| After report run | 10+ seconds | Report processing |
| After dropdown | 1 second | Options load |
| After form submit | 5 seconds | Save processing |
